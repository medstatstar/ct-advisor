## 1. 关中心（Site Closeout）全流程实操

### 1.1 关中心启动前提（尾款结算前必须满足的 6 项）

| # | 前提条件 | 验证方式 |
|---|---|---|
| ① | 受试者随访全部完成（含计划外访视/SAE 随访） | eCRF 完成状态 + 医学确认 |
| ② | 所有数据疑问（Query）关闭 | EDC 系统 Query 状态 = Closed |
| ③ | 试验药物回收/销毁完成（含空包装、剩余药液） | 药房清点记录 + 销毁见证 |
| ④ | 生物样本状态明确（已检测/销毁/转运） | 实验室样本追踪表 |
| ⑤ | SAE/SUSAR 报告时限内完成（含关中心后随访期内新获知的 SAE） | 安全数据库 + 锁库确认 |
| ⑥ | 财务结算尾款已支付 | 机构财务到账凭证 |

⚠️ 以上 6 项缺一不可；尾款到账 ≠ 自动关中心，必须逐项核查。

### 1.2 关中心顺序（尾款到账后的标准执行链）

```
尾款到账确认
  → ① 末次监查报告（close-out visit / COV）完成
  → ② 剩余物资回收（药物、设备、试剂、日记卡等）
  → ③ 纸质资料清点与销毁评估
  → ④ 机构归档预约（向机构办/GCP 药房预约归档时间）
  → ⑤ 伦理结题申请提交（结题报告 + 总结报告）
  → ⑥ 纸质资料销毁（伦理结题批准后执行）
  → ⑦ 关中心小结撰写与归档
  → ⑧ ISF/eTMF 移交与锁库
  → ⑨ 关闭授权签名与系统权限回收
```

⚠️ **归档预约 → 伦理结题 → 纸质销毁** 的顺序：**先预约归档 → 伦理结题批准 → 再销毁纸质资料**。伦理结题批准前不得销毁任何试验资料。

### 1.3 纸质资料销毁操作规范

**销毁范围**：受试者日记卡、已填写的原始 CRF（如为纸质 CRF）、受试者筛选入选表、已签署 ICF 副本等含个人信息资料。

**不得销毁**：ISF 原件（研究者文件夹）、伦理批件、试验药物原始记录、SAE 原始报告——这些必须归档。

**销毁流程**：
1. 确认伦理结题批准文件已获取
2. 清点待销毁资料清单（逐份登记编号/受试者编号）
3. 双人见证销毁（通常为 CRA + 机构 GCP 药房/机构办人员）
4. 销毁方式：纸质 → 碎纸机（交叉碎）或专业销毁公司；电子 → 覆写/物理销毁
5. **销毁记录**必须归档（含清单、见证人签字、销毁日期、销毁方式）

### 1.4 关中心小结撰写（谁写、什么内容）

**撰写人**：**CRA 起草，PM 审核，PI 确认**。机构 GCP 药房/机构办通常只接收不撰写。

**最小内容框架**：
1. 中心基本信息（中心编号、PI、启动日期、末例受试者末次访视日期）
2. 入组与完成（筛选数/入组数/完成数/脱落数/剔除数）
3. 方案违背汇总（按类别统计 + 重大违背摘要）
4. SAE 汇总（发生率/相关性/转归）
5. 试验药物管理总结（回收/销毁/温度偏离记录）
6. 数据管理总结（Query 数量/关闭率/锁库日期）
7. 样本管理总结（检测/销毁/转运状态）
8. 遗留问题与后续计划
9. 声明：本中心试验资料已按规定归档/销毁

## 2. HGR（人类遗传资源）自查实操

### 2.1 判断是否需 HGR 审批的 4 步法

```
Step 1: 本试验是否涉及人类遗传资源材料？
  → 含：血液、组织、唾液、尿液、DNA/RNA 提取、FFPE 切片 → 进入 Step 2
  → 纯临床数据回顾（无生物样本） → 一般不涉及 HGR

Step 2: 是否涉及「采集」或「保藏」？
  → 采集：为本次试验专门采集血液/组织用于基因检测 → 需要审批
  → 保留：本次试验产生的样本长期保存 → 需要审批
  → 仅利用已有库存样本（回顾性研究） → 看 Step 3

Step 3: 是否涉及「对外方单位开放」或「出境」？
  → 外方单位（申办方/CRO/第三方实验室）可接触样本或数据 → 需要审批
  → 仅中方单位使用，不外传 → 看 Step 4

Step 4: 是否属于豁免情形？
  → 以下一般豁免 HGR 审批（但仍需机构确认）：
    ① 为临床诊疗目的采集的样本（非试验必需）
    ② 已获 HGR 批准的其他试验样本再利用
    ③ 仅使用血常规/生化等常规检验剩余血（非基因检测）
    ④ 涉及人类遗传资源但不在 HGR 法规管辖范围（如纯合成数据）
```

### 2.2 关中心项目 HGR 自查清单

| 检查项 | 结论 |
|---|---|
| 本中心是否做过 HGR 审批？ | 查 HGR 申报平台 → 有记录 → 进入后续 |
| 关中心后样本是否继续保留？ | 是 → 需办理样本处置变更 / 销毁 |
| 数据是否已传输至外方？ | 是 → 确认在 HGR 许可范围内 |
| 关中心报告中是否需要体现 HGR 执行情况？ | 是 → 关中心小结应含 HGR 合规声明 |

## 3. 伦理结题与归档预约实操

### 3.1 伦理结题申请材料清单

- 结题报告（含试验完成摘要、SAE 总结、方案违背统计）
- 关中心小结（CRA 起草 + PI 签字）
- 受试者知情同意书履行情况说明
- 试验药物回收/销毁证明
- 数据锁库确认函
- 机构要求的其他材料（因机构而异，须查 SOP）

### 3.2 归档预约流程

1. 联系机构 GCP 药房/机构办 → 预约归档时间
2. 准备 ISF 原件（按机构归档目录整理）
3. 归档当日双方清点 → 签署归档交接单
4. 归档后机构出具 **《临床试验资料归档证明》**——关中心闭环证据

## 4. 给药周期计算规则（methodology:E）

### 4.1 因毒性暂停后恢复给药的周期计算

**原则**：周期 = 从本周期**首次给药**之日 → 下一周期首次给药之日（含延迟天数）。

**实操**：
- 21 天周期，D1 给药后因毒性暂停 D8-D21 → 恢复时仍记为同一周期
- 实际给药日顺延 → 周期长度 = 实际给药间隔天数（如 21 + 暂停天数）
- **CRF 记录**：记录实际给药日期 + 延迟原因 + 剂量调整情况
- **SAP 预设**：通常预设最大延迟天数（如 2 周），超窗为方案违背

### 4.2 周期数与剂量调整记录模板

| 字段 | 记录内容 |
|---|---|
| 计划周期 | 如 "Cycle 2" |
| 计划给药日 | 按计划应为 D1 = YYYY-MM-DD |
| 实际给药日 | 因毒性顺延至 YYYY-MM-DD |
| 延迟天数 | 7 天 |
| 延迟原因 | 3 级中性粒细胞减少 |
| 剂量调整 | 维持原剂量 / 降低至 75% / 永久停药 |

## 5. MedDRA PT 编码实操

### 5.1 编码四步法

```
Step 1: 获取原始 AE 名称（来自受试者主诉/病历记录）
Step 2: 在 MedDRA 浏览器中检索（sm.meddra.org 或授权终端）
Step 3: 选择最匹配的 LLT → 自动映射到 PT
Step 4: 验证 PT 语义一致性
```

### 5.2 高频 AE 名称与 PT 映射示例

| 原始 AE 名称 | 正确 PT | 常见错误 |
|---|---|---|
| 既往感染结核杆菌阳性 | Latent tuberculosis | Tuberculosis（活动性 TB ≠ 潜伏感染） |
| 免疫相关性肺炎 | Immune-mediated pneumonitis | Pneumonitis（未体现 ICI 机制） |
| 输注相关反应 | Infusion related reaction | Allergic reaction / Anaphylaxis |
| 甲状腺功能减退 | Hypothyroidism | Blood thyroid stimulating hormone decreased |
| 皮疹 | Rash | Rash maculo-papular / Dermatitis |

### 5.3 编码注意

- 一个 AE 可映射多个 PT（如 "肝酶升高" → Hepatic enzyme increased + Alanine aminotransferase increased）
- 等级/严重程度 ≠ 不同 PT（3 级贫血 → Anaemia，不改变 PT）
- 死亡 → 不编码为 PT "Death"，而是死亡原因 + 严重程度 = 5 级

## 6. 研究背景撰写模板（methodology:E）

### 6.1 III 期试验研究背景最小结构（2000-3000 字）

```
1. 疾病流行病学负担（10-15%）
   - 全球/中国发病率、死亡率、疾病负担数据（引用最新指南/文献）
   - 目标人群特征（年龄、分期、分子分型）

2. 当前治疗格局与临床困境（25-30%）
   - 标准治疗（SOC）及其疗效天花板
   - 未满足临床需求（耐药、毒性、生活质量）
   - 最新指南推荐与变迁（引用年份版本）

3. 试验药物机制与早期证据（25-30%）
   - 作用机制（MOA）
   - I/II 期关键试验结果（主要疗效/安全性数据）
   - 与现有治疗的优势假设

4. 关键 RCT 证据（如适用）（10-15%）
   - 同类或同靶点已发表 III 期试验摘要
   - 本试验设计的差异化优势

5. 本试验必要性总结（10%）
   - 一句话结论：为何现在必须做这个试验
```

### 6.2 写作注意

- 每段数据必须有引用（指南/文献/临床试验注册号）
- 避免使用"全球首创""同类最优"等营销词汇
- 背景不等于方案——不写具体入排标准/给药方案（属于方案正文）
- 数字与年份必须核实原文，禁止凭记忆填写
