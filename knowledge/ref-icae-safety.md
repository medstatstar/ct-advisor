# Immune Checkpoint Inhibitor (ICI) Safety Profile / 免疫检查点抑制剂安全性速查

> **适用场景**：irAE 机制解释、因果关系判定、ICI 类间安全性比较、特定 AE（带状疱疹/VZV 再激活、间质性肺炎、心肌炎等）的循证依据查询。

## 1. ICI 分类与 irAE 谱概述

| 类别 | 代表药物 | irAE 谱特征 |
|---|---|---|
| **PD-1 单抗** | 帕博利珠单抗、纳武利尤单抗、信迪利单抗、替雷利珠单抗 | 甲状腺功能异常（10–20%）、肺炎（2–5%）、肝炎（1–3%）、结肠炎（1–2%）、皮肤毒性（10–30%，含皮疹/瘙痒）、VZV 再激活（3–7%） |
| **PD-L1 单抗** | 阿替利珠单抗、度伐利尤单抗 | 与 PD-1 单抗类似但甲状腺炎发生率略低；肺炎/肝炎风险相当 |
| **CTLA-4 单抗** | 伊匹木单抗 | 结肠炎（10–20%，3–4级 5–8%）、垂体炎（5–10%）、皮疹/瘙痒（40–50%）；单药 irAE 发生率高于 PD-1 单抗 |
| **PD-1/VEGF 双抗** | 恩沃利单抗（envafolimab）、卡度尼利单抗（cadonilimab，PD-1/CTLA-4 双抗） | 总体 irAE 谱与 PD-1 单抗单药相当；VEGF 通路阻断不额外增加 VZV 再激活风险；卡度尼利单抗因含 CTLA-4 臂，结肠炎/垂体炎发生率高于 PD-1 单抗单药 |
| **PD-1/CTLA-4 双抗** | 卡度尼利单抗 | irAE 发生率介于 PD-1 单抗单药与 CTLA-4 单抗单药之间；3–4级 irAE 约 15–25% |

> ⚠️ 以上为类别特征概述，具体发生率因瘤种、剂量、联合方案而异；引用具体数字时核对原始文献。

## 2. VZV/HSV 再激活（带状疱疹）——PD-1/PD-L1 抑制剂

### 2.1 生物学机制

- **核心通路**：PD-1/PD-L1 是 T 细胞耗竭的关键调控通路。生理状态下，VZV 特异性 CD8⁺ 记忆 T 细胞通过识别 VZV 抗原控制病毒潜伏；PD-1 抑制剂阻断该通路后，一方面激活效应 T 细胞引发 irAE，另一方面可导致潜伏 VZV 的神经元中病毒特异性 CD8⁺ T 细胞功能失调，无法有效抑制病毒复制 → VZV 再激活 → 带状疱疹。
- **关键细胞**：VZV 特异性 CD8⁺ 组织驻留记忆 T 细胞（TRM）功能受损是核心环节。
- **VEGF 通路**：目前无证据显示 VEGF 通路阻断（贝伐珠单抗类）会额外增加 VZV 再激活风险；PD-1/VEGF 双抗的带状疱疹发生率与 PD-1 单抗单药相当。

### 2.2 流行病学数据（文献范围，非精确值）

| 人群 | 年发病率范围 | 关键文献 |
|---|---|---|
| 一般人群（≥50 岁） | 约 5‰–15‰ | 《中华皮肤科杂志》2021；Lancet Infect Dis 综述 |
| 实体瘤患者（未接受 ICI） | 约 15‰–30‰ | JAMA Oncol 2020; J Clin Oncol 2021 |
| 接受 PD-1/PD-L1 单抗治疗的实体瘤患者 | 约 3%–7%（总体）；3 级及以上 0.5%–1.5% | JAMA Oncol 2020（系统综述，n>10,000） |
| PD-1/PD-L1 单抗 + 化疗联合 | 约 8%–12% | 同上 |
| PD-1/VEGF 双抗（恩沃利单抗） | 约 4%–7%，与 PD-1 单抗单药相当 | 各产品说明书/关键试验安全性数据 |

> ⚠️ 发病中位时间：首次用药后约 12–20 周（范围 2–48 周）；末次给药后 30 天内仍为高风险窗。
> ⚠️ 以上数据为文献范围值，具体数字因研究设计/瘤种/随访时长而异；引用时核对原始文献。

### 2.3 高危因素

- 年龄 ≥70 岁（独立风险因素）
- 晚期肿瘤（尤其血液肿瘤、接受高强度化疗者）
- 既往带状疱疹病史
- 合并糖尿病、长期使用糖皮质激素、其他免疫抑制状态
- ICI 联合治疗（PD-1 + CTLA-4 或 ICI + 化疗）

### 2.4 管理原则（NCCN/ASCO 止吐与感染指南综合）

- **筛查**：首次 ICI 治疗前建议筛查 VZV 抗体（IgG）；阳性者（曾感染水痘/带状疱疹）为再激活高危。
- **预防**：目前 NCCN/ASCO 指南**不推荐**常规预防性抗病毒治疗；但高危人群（≥70 岁+晚期肿瘤+ICI）可考虑阿昔洛韦/伐昔洛韦预防（需个体化评估）。
- **治疗**：发生带状疱疹后按标准抗病毒治疗（阿昔洛韦/伐昔洛韦/泛昔洛韦），同时评估是否暂停 ICI；1 级（<3 皮节、无并发症）可在密切监测下继续；≥2 级暂停 ICI，待恢复至 ≤1 级后重启。
- **再挑战**：既往发生带状疱疹后是否重启 ICI 需个体化；若重启后再次发生，需永久停用同类 ICI。

## 3. 其他关键 irAE 速查

### 3.1 免疫性肺炎（ICI-pneumonitis）

- **发生率**：PD-1 单抗单药 2–5%；联合治疗 5–10%；3 级及以上 1–2%。
- **中位发生时间**：首次用药后 2–6 个月。
- **高危因素**：肺癌（尤其合并放疗史）、既往间质性肺病、吸烟史。
- **管理**：1 级（影像学异常，无症状）→暂停 ICI + 观察；2 级（症状性，不影响 ADL）→暂停 ICI + 泼尼松 1 mg/kg；3–4 级→永久停用 ICI + 甲泼尼龙 2–4 mg/kg + 感染排除。

### 3.2 免疫性心肌炎（ICI-myocarditis）

- **发生率**：PD-1 单抗单药 <0.5%；PD-1 + CTLA-4 联合约 1–2%；致死率高（25–50%）。
- **中位发生时间**：首次用药后 1–3 个月（可早至首剂后 1 周内）。
- **高危因素**：PD-1 + CTLA-4 联合、既往心血管疾病、糖尿病。
- **管理**：任何级别均永久停用 ICI；立即心内科会诊 + 大剂量甲泼尼龙（1 g/日）+ 必要时 ATG/MMF。

### 3.3 免疫性肝炎（ICI-hepatitis）

- **发生率**：PD-1 单抗单药 1–3%；CTLA-4 单抗 3–5%；联合 10–15%；3 级及以上 1–2%（单药）/ 5–10%（联合）。
- **中位发生时间**：首次用药后 6–14 周。
- **管理**：1 级（ALT/AST >1–3×ULN）→继续 ICI + 监测；2 级（3–5×ULN）→暂停 ICI + 泼尼松 0.5–1 mg/kg；3–4 级（>5×ULN）→永久停用 + 甲泼尼龙 1–2 mg/kg + 霉酚酸酯。

### 3.4 免疫性肾炎（ICI-nephritis）

- **发生率**：PD-1 单抗单药 1–2%；联合 3–5%；3 级及以上 <1%。
- **中位发生时间**：首次用药后 2–4 个月。
- **管理**：1 级（Cr 1.5–2×基线）→继续 + 监测；2 级（2–3×基线）→暂停 + 泼尼松 1 mg/kg；3–4 级→永久停用 + 肾活检 + 免疫抑制。

### 3.5 甲状腺功能异常（ICI-thyroiditis）

- **发生率**：PD-1 单抗单药 10–20%（甲减为主）；CTLA-4 单抗 5–10%；联合 15–30%。
- **特点**：常先出现甲亢（破坏性甲状腺炎），数周后转为甲减；多为 1–2 级，罕见 3–4 级。
- **管理**：甲亢期 β 受体阻滞剂对症；甲减期左甲状腺素替代；无需停用 ICI（除非合并甲状腺危象）。

### 3.6 垂体炎（ICI-hypophysitis）

- **发生率**：CTLA-4 单抗 5–10%（伊匹木单抗最高）；PD-1 单抗 <1%；联合 5–10%。
- **特点**：头痛、疲劳、恶心、低钠血症；MRI 示垂体增大。
- **管理**：暂停 ICI + 糖皮质激素（甲泼尼龙 1 mg/kg）+ 激素替代（肾上腺皮质功能减退者终身替代）。

## 4. 因果关系判定要点（CDE 五分法 + ICI 特殊性）

当 ICI 治疗患者出现 AE 需判定因果关系时，除常规五分法要素外，**ICI 特有考量**：

| 要素 | ICI 特殊考量 |
|---|---|
| **时间相关性** | irAE 中位发生时间因器官而异（心肌炎 1–3 月、肺炎 2–6 月、肝炎 6–14 周、VZV 再激活 12–20 周）；"时间窗"需按具体 irAE 类型判断，不能一概而论 |
| **去激发** | 多数 irAE 停药后可缓解（支持相关）；但部分 irAE（如甲状腺功能异常、1 型糖尿病）可能不可逆——不可逆 ≠ 不相关 |
| **再激发** | ICI 再挑战需极其谨慎：心肌炎/肝炎/肾炎 3–4 级永久禁用；肺炎/结肠炎 2 级再发后永久禁用；皮肤/甲状腺 1 级可在密切监测下尝试 |
| **已知不良反应** | 需核对 ICI 说明书及类效应数据；PD-1/VEGF 双抗的 irAE 谱与 PD-1 单抗单药相当（VEGF 通路不额外增加 VZV 风险） |
| **其他解释** | 高龄+肿瘤本身+合并治疗（化疗/放疗/糖皮质激素）均为混杂因素；需明确"不能完全用其他原因解释"方可判定"很可能有关" |

## 5. PD-1/VEGF 双抗 vs PD-1 单抗安全性对比

| 安全性指标 | PD-1 单抗单药 | PD-1/VEGF 双抗（恩沃利单抗） | 备注 |
|---|---|---|---|
| 总体 irAE 发生率 | 60–70%（1–2 级为主） | 约 60–70%，相当 | 各产品说明书 |
| 3–4 级 irAE | 10–20% | 约 10–20%，相当 | — |
| 带状疱疹/VZV 再激活 | 3–7% | 4–7%，相当 | VEGF 通路不额外增加风险 |
| 免疫性肺炎 | 2–5% | 约 2–5%，相当 | — |
| 免疫性肝炎 | 1–3% | 约 1–3%，相当 | — |
| 高血压（VEGF 相关） | 无/极低 | 约 5–10%（1–2 级） | VEGF 通路特有 |
| 蛋白尿（VEGF 相关） | 无/极低 | 约 3–5%（1–2 级） | VEGF 通路特有 |
| 出血（VEGF 相关） | 无/极低 | 约 1–3%（多为鼻出血） | VEGF 通路特有 |

> ⚠️ 以上对比基于各产品关键试验安全性数据；具体数字因试验设计/瘤种/剂量而异，引用时核对原始文献。
