## 1. 安全性信号检测实操

### 1.1 信号检测四步法

```
Step 1: 数据源确认
  → 临床试验 SAE 列表（安全数据库）
  → 上市后自发报告（FAERS/VigiBase/国家 ADR 监测系统）
  → 文献病例（PubMed/Embase）

Step 2: 定量信号检测
  → 计算 PRR（Proportional Reporting Ratio）
  → 计算 ROR（Reporting Odds Ratio）
  → 计算 EBGM（Empirical Bayes Geometric Mean）
  → 阈值：PRR≥2 + χ²≥4 + ≥3 例 → 信号触发

Step 3: 定性信号评估
  → 因果关系评估（时间相关性、去激发/再激发、替代解释）
  → 生物学合理性（机制是否支持）
  → 同类药物安全性特征

Step 4: 信号分级与行动
  → 确认信号 → 更新 RSI/IB/说明书
  → 疑似信号 → 加强监测 + 定期评估
  → 排除信号 → 记录理由
```

### 1.2 PRR/ROR 计算模板

| 参数 | 定义 |
|---|---|
| a | 目标药物 + 目标 AE 的报告数 |
| b | 目标药物 + 其他 AE 的报告数 |
| c | 其他药物 + 目标 AE 的报告数 |
| d | 其他药物 + 其他 AE 的报告数 |

```
PRR = (a/(a+b)) / (c/(c+d))
ROR = (a/b) / (c/d) = ad / bc
```

## 2. ICI irAE 管理速查

### 2.1 常见 irAE 分级与处理原则

| irAE | 1级 | 2级 | 3级 | 4级 |
|---|---|---|---|---|
| 皮疹/皮炎 | 局部激素 | 口服激素 0.5-1 mg/kg | 口服激素 1-2 mg/kg + 暂停 ICI | 永久停药 + 静脉激素 + 专科会诊 |
| 甲状腺功能异常 | 监测 | 激素替代/甲亢治疗 | 暂停 ICI + 治疗 | 永久停药（罕见） |
| 免疫性肺炎 | 无症状，观察 | 有症状，口服激素 | 静脉激素 + 暂停 ICI | 永久停药 + 静脉激素 + ICU |
| 免疫性肝炎 | ALT/AST <3×ULN | ALT/AST 3-5×ULN | ALT/AST 5-20×ULN | ALT/AST >20×ULN 或肝衰竭 |
| 免疫性结肠炎 | 腹泻 <4次/天 | 腹泻 4-6次/天 + 口服激素 | 腹泻 >6次/天 + 静脉激素 | 肠穿孔/出血 |

### 2.2 ICI 因果关系判定要点

1. **时间相关性**：irAE 通常在用药后 2-12 周出现（但可更晚）
2. **去激发**：停药后改善支持因果关系
3. **再激发**：再次用药后复发（再激发阳性是强证据，但伦理上通常禁止故意再激发）
4. **替代解释**：排除感染、肿瘤进展、其他药物
5. **生物学合理性**：ICI 机制（T 细胞过度激活）支持

## 3. SUSAR 报告实操

### 3.1 报告时限（中国 NMPA）

| 报告类型 | 时限 | 起始点 |
|---|---|---|
| 致死或危及生命的 SUSAR | **7 个日历日** | 申办方首次获知 |
| 其他 SUSAR | **15 个日历日** | 申办方首次获知 |
| 妊娠暴露 | **与 SUSAR 相同** | 申办方首次获知 |

⚠️ "首次获知" = 申办方任何员工/代理首次获知该 SAE 之日，非 CRA 获知之日。

### 3.2 SUSAR 报告最小数据集

- 可识别的受试者（编号/随机号）
- 可疑药物（试验药/安慰剂/对照药）
- AE 描述（诊断/症状 + 严重程度 + 因果关系）
- 报告来源（研究者/文献/监管）
- 报告日期与获知日期

### 3.3 中国 SUSAR 报告路径

```
研究者获知 SAE → 报告申办方（24h 内）
  → 申办方评估是否为 SUSAR
    → 是 → 7/15 日内通过 NMPA 直报系统提交
    → 否 → 定期汇总至 DSUR/PSUR
```

## 4. 妊娠暴露处理

### 4.1 妊娠暴露报告流程

1. **确认妊娠**：尿/血 hCG 阳性 + 超声确认
2. **评估暴露窗口**：末次月经 → 受孕日 → 用药日 → 是否器官形成期暴露
3. **报告时限**：按 SUSAR 时限（致死/危及生命 7 日，其他 15 日）
4. **随访**：妊娠结局（分娩/流产/终止）+ 婴儿出生缺陷监测
5. **记录**：妊娠暴露登记表 + 长期随访（通常至婴儿 1 岁）

### 4.2 妊娠暴露因果关系评估

| 要素 | 评估要点 |
|---|---|
| 时间相关性 | 暴露是否在器官形成期（受孕后 3-8 周） |
| 生物学合理性 | 该药物是否有已知致畸性/生殖毒性 |
| 同类药物 | 同类药物妊娠安全性数据 |
| 背景率 | 该畸形在一般人群中的背景发生率 |

## 5. 死亡报告

### 5.1 死亡 SAE 报告要点

- **死亡日期**与**末次用药日期**的间隔
- **死因**：AE 导致 / 疾病进展 / 其他
- **因果关系**：研究者判断（肯定/可能/无关）
- **尸检**：是否进行 + 结果（如有）
- **时限**：致死 SUSAR → 7 个日历日

### 5.2 死亡 SAE 报告模板

```
1. 受试者信息：编号/随机号/年龄/性别
2. 死亡信息：死亡日期/地点/是否尸检
3. 死因：直接死因 + 根本死因
4. 试验药物：末次用药日期/剂量/周期
5. 因果关系：研究者判断 + 依据
6. 报告：是否符合 SUSAR → 是/否
```

## 6. 过量用药（Overdose）处理

### 6.1 过量用药定义

- 实际给药剂量 > 方案规定剂量
- 给药频率 > 方案规定
- 给药途径错误（如静脉误给动脉）

### 6.2 处理流程

1. **立即**：评估受试者安全性 + 对症处理
2. **报告**：按方案违背 + SAE（如导致伤害）
3. **记录**：过量剂量/频率/原因/处理/转归
4. **随访**：监测相关 AE 至缓解
5. **方案违背**：记录为 PD + 评估是否为重大违背

## 7. RMP（Risk Management Plan）要点

### 7.1 RMP 核心模块

| 模块 | 内容 |
|---|---|
| 安全性规格 | 已识别风险 + 潜在风险 + 缺失信息 |
| 药物警戒计划 | 常规 PV + 额外 PV 活动 |
| 风险最小化措施 | 常规措施 + 额外措施（如教育材料、妊娠预防计划） |
| 有效性评估 | RMP 有效性评估计划 |

### 7.2 中国 RMP 特殊要求

- 中国 RMP 需包含中国人群数据（如可用）
- 妊娠预防计划（PPP）通常要求
- 额外风险最小化措施需与 NMPA 协商

## 8. 安全性数据库锁库

### 8.1 锁库前检查清单

- [ ] 所有 SAE 已录入并核查
- [ ] 所有 SUSAR 已报告
- [ ] 妊娠暴露已登记并随访
- [ ] 死亡病例已完整报告
- [ ] 因果关系评估已完成
- [ ] 数据库 QC 已完成（逻辑核查 + 医学审核）
- [ ] 锁库日期已记录

### 8.2 锁库后变更

- 锁库后变更需**正式的数据库解锁流程**
- 变更需记录原因、日期、操作人
- 变更后需重新 QC + 重新锁库
